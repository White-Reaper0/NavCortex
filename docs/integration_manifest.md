# P.R.I.S.M. integration manifest

This is an auditable status record for the offline replay prototype. Versions
and compatibility are evidence, not a claim that every listed project is active.

| Component | Official source | License / version evidence | Status and interface |
| --- | --- | --- | --- |
| OpenCV | https://github.com/opencv/opencv | Existing `.venv`: `opencv-python 5.0.0.93`; Apache-2.0 upstream | **Active**: decode and existing ORB visual-motion replay. |
| COLMAP | https://github.com/colmap/colmap | Existing local `tools/external/colmap/4.2.1-nocuda`; native model inspected only | **Active diagnostic input** through `prism.colmap_inspection`; local-only with bundled-component licensing caveat. No rerun or redistribution. |
| LibreYOLO / LibreYOLO9t | https://github.com/LibreYOLO/libreyolo; https://huggingface.co/LibreYOLO/LibreYOLO9t | `libreyolo==1.6.0`; local asset hash `b4d7e93f9e0393830fb42e6135c0e3464b2673b05e5ecf4b7f2374ec18e39eb2`; local provenance says MIT implementation/model-card | **Active when checkpoint loads** through `prism.libreyolo_provider`. Typed 2-D evidence only. No Ultralytics package/weights. |
| Open3D | https://github.com/isl-org/Open3D | Installed `.venv`: `open3d==0.20.0`; MIT; Windows CPython 3.11 wheel | **Active optional**: `prism.integrations.geometry.open3d_sparse_inspection` loads native COLMAP XYZ/RGB without rescaling; integrated replay may export `sparse_points_open3d_native.ply`. |
| stella_vslam | https://github.com/stella-cv/stella_vslam | BSD-2-Clause; official installation documentation recommends WSL for Windows 10 and requires C++ dependencies including g2o/SuiteSparse/FBoW | **Blocked optional**: `prism.integrations.localization.localization_backend_report` records `wsl --status` probe results and build/WSL blockers; no binary vendored under `tools/external/`. |
| RTAB-Map | https://github.com/introlab/rtabmap | BSD-3-Clause upstream | **Blocked optional**: monocular RGB clip only; no ROS/GPU; synthetic depth from COLMAP is prohibited. Status exported in `localization_backends.json`. |
| Grid Map | https://github.com/ANYbotics/grid_map | BSD-3-Clause; upstream LICENSE re-verified 2026-10-24; ROS ecosystem dependency | **Concept adapted**: `prism.integrations.terrain_grid` implements ROS-free layers (elevation/support/step/slope/roughness/traversability/confidence/age) over `BEVMap`; unknown cells stay UNKNOWN; variance/normals are not fabricated. No upstream source copied. |

The deterministic IoU fallback is used only if that optional import/runtime fails. |
| Provider contract | Project-owned | `prism/integrations/provider_contract.py` | **Active**: runtime-checkable `FrameObservationProvider` (`config`, `__call__(DecodedFrame) -> VideoReplayInput`); no control output. |
| IP Webcam source | Android IP Webcam app; project-owned adapter | No third-party library vendored; app serves MJPEG at `http://<phone-ip>:8080/video` | **Experimental, advisory-only**: `tools/run_prism_ipwebcam.py` captures a bounded MJPEG stream, applies the LibreYOLO 2-D provider and image tracking, and runs ORB diagnostics on the recorded clip. No vehicle command; physical-camera validation unverified. |
| Native live workbench | project-owned; reuses OpenCV (window) and Open3D (optional viewer) already in `.venv` | `tools/run_prism_live_viewer.py`; `tests/test_live_viewer.py` + `tests/test_live_viewer_pretrained.py` (114 tests); `docs/live_viewer_workbench.md` | **Experimental, advisory-only**: a native resizable OpenCV desktop window (no browser, web server, React or Electron) over a PC webcam or the phone MJPEG stream. Draws LIVE capabilities - LibreYOLO 2-D boxes, Norfair/IoU image-space tracks, ORB/fundamental motion diagnostics, optional YOLOP statistics, real `BeliefLedger`/`DoubtEngine`/`RuntimeAdapter` state, plus the pretrained depth, segmentation, geometric-BEV terrain and single-frame point-cloud views below. Metric terrain/active mapping stay blocked cards that name the missing artifact; 3-D reconstruction is the existing offline COLMAP path in one bounded background worker, reported `RELATIVE_ONLY` / `METRIC_SCALE_UNVERIFIED`. `prism/runtime.py`, `prism/nav/planner.py`, `prism/nav/supervisor.py` and `ros2/` are not imported. No camera or socket was opened during implementation or tests; a bounded headless run with the real models succeeded with every socket blocked. |
| Depth Anything V2-Small (HF) | https://huggingface.co/depth-anything/Depth-Anything-V2-Small-hf | Apache-2.0 per the downloaded model card; revision `5426e4f0f36572d16453bbda7a8389317b1bef99`; `model.safetensors` SHA-256 `3152477ce0d8d6978d76b995120de97cb5b928701fd0f817769f59e249a16b70`; loaded through `transformers==4.57.6` with `local_files_only=True` on CPU | **Active in the workbench and the offline depth stage** through `prism.models.depth.DepthStage` + `prism.models.pretrained_paths`. ADE20K semantics mapped onto the existing prism-7 taxonomy, `IGNORE_INDEX` for unmapped classes; explicitly not traversability and not ground truth. Local-only, gitignored. |
| torchvision MobileNetV3-Small (ImageNet1K_V1) | https://download.pytorch.org/models/mobilenet_v3_small-047dcff4.pth | Distributed with PyTorch/torchvision (BSD-3-Clause code); SHA-256 `047dcff4addef86ea5bc2eff13c9614dc11f47ab1160d0a71a25e7db994f4e1f`; lives in the shared TorchHub cache, outside the repo | **Available as an initialisation only** for the project's own 17-channel terrain architecture in the future training path. | LibreDepthAnything3l-depth | https://huggingface.co/LibreYOLO/LibreDepthAnything3l-depth | Non-YOLO neural depth candidate | **Still excluded**: the operator's 2026-10-25 approval covers only the three named assets above, so no weights or dependencies were downloaded for this candidate. | LibreMiDaSs-depth | https://huggingface.co/LibreYOLO/LibreMiDaSs-depth | Non-YOLO neural depth candidate | **Still excluded**: same narrow supersession as above; nothing downloaded. |

The selected operational localization backend is the existing **OpenCV tracking-only + COLMAP sparse diagnostic path**. Its outputs are relative-only unless separately calibrated and scale-aligned. It is not a localization accuracy claim.
